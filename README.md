# tauri-plugin-dock

Windows-native Dock component for Tauri 2, built as a Rust plugin with an embedded Win32/Direct2D renderer and TypeScript bindings.

**Experimental:** this initial port is not yet a production replacement for the original Dock executable.

## Install

Add the Rust plugin as a Git dependency:

```toml
tauri-plugin-dock = { git = "https://github.com/Mesrine67/tauri-plugin-dock" }
```

Register with `.plugin(tauri_plugin_dock::init())` inside your Tauri 2 builder. Give the host window only required `dock:allow-*` permissions.

The JavaScript bindings are located in `guest-js/index.ts`. No npm package has been published.

## Architecture

- Rust Tauri commands with autogenerated permissions.
- C++17/Win32/Direct2D native renderer compiled into the application via MSVC, not a standalone executable.
- The original Dock's native Settings dialog remains available during migration.
- The host Tauri application is responsible for tray integration, global shortcuts, autostart and updates.
- Windows 10/11 x64 only.

See `docs/FXMP-MIGRATION.md` for the settings checklist and required acceptance tests.
